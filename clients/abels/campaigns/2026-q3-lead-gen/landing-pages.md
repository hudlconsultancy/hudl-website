## Implementation notes (both pages)

1. **Message match:** the hero H1 on each page must align with the pinned headline in the corresponding RSA. Do not change one without changing the other.
2. **Above-fold CTA:** on mobile, the quote button must be visible without scrolling. If the hero image takes up full viewport height, shorten it or overlay the CTA on the image.
3. **Phone number:** must be click-to-call on mobile. Google Ads can track phone-number clicks as a conversion — ensure this is set up in the Google Ads account.
4. **[PLACEHOLDER] items:** every item labelled [PLACEHOLDER] in this document must be replaced with verified content before the page is published. Do not publish with placeholder text visible to users.
5. **Form submission → GA4 key event:** confirm with the developer that step 1 form submission fires a GA4 key event (conversion goal). This is how the quote-form completion rate KPI (brief §1 target: +10–20% relative to ~4.1%) will be tracked.
6. **Thank-you page:** the existing `thank-you.html` should confirm: what happens next, the response SLA [X hours], and a reassurance line. Ensure this page also fires the GA4 conversion event if the form redirects rather than using inline confirmation.
7. **Page load:** run both pages through Google PageSpeed Insights before go-live. Target 90+ on mobile. Slow pages disproportionately hurt paid traffic (users can immediately return to the SERP).
8. **Trust slot go-live dependency:** if verified testimonials/review counts are not available in time for the w/c 7 July launch, omit the trust slot entirely rather than launch with a placeholder. A clean page converts better than one with obviously missing content.
