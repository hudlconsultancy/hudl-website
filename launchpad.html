Agent Launch Pad

Your team of AI specialists for the HUDL business — built as Claude Code subagents. Each one knows your brand, your data and your formats, and works in a dedicated workspace per client. Spin one up to crunch campaign numbers, write a post, build a client dashboard or draft outreach that converts.

How it works
01

Open Claude Code

In this repo — on the web at claude.ai/code, the desktop app, or the CLI. The agents live in .claude/agents/ and load automatically.

02

Call an agent

Type @ and the agent name, then your request — or just describe the task and Claude routes it to the right specialist for you.

03

Review & ship

Each agent produces real files or copy in your formats. Review the diff, then commit & push — or ask the agent to do it.
