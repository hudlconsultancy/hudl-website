🧠 The Brain — shared memory

Every agent reads BRAIN.md before any task — your voice, the rules that never change, current priorities and the client map. And each client folder has a decisions.md that logs your corrections and preferences, so the team never has to be told the same thing twice. Teach them once; it sticks.

To teach the team something new: "Remember for Abels: always lead with the accreditation." → it gets logged to clients/abels/decisions.md

How it works
01

Open Claude Code

In this repo — on the web at claude.ai/code, the desktop app, or the CLI. The agents live in .claude/agents/ and load automatically.

02

Call them by name

Copy a quick action above, or just say "Hunter, what should I do today?" Talk to them in plain English by name — Pippa, Hendrix, Dash, Otis, Solo — or let Hunter route it.

03

Review & ship

Deliverables land in the client workspace — social packs, reports, copy, campaigns. Use the Workspace → links in the Clients section to browse them on GitHub, or ask the agent to display a file directly.
