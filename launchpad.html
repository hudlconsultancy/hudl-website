🧠 The Brain — shared memory

Every agent reads BRAIN.md before any task — your voice, the rules that never change, current priorities and the client map. And each client folder has a decisions.md that logs your corrections and preferences, so the team never has to be told the same thing twice. Teach them once; it sticks.

To teach the team something new: "Remember for Abels: always lead with the accreditation." → it gets logged to clients/abels/decisions.md
Client Workspaces

Each client has a dedicated folder under clients/. When you name a client, the agent reads their profile.md for context and their decisions.md for your saved preferences, works from their data/, and files deliverables into reports/, content/ or outreach/.

How it works
01

Open Claude Code

In this repo — on the web at claude.ai/code, the desktop app, or the CLI. The agents live in .claude/agents/ and load automatically.

02

Call them by name

Copy a quick action above, or just say "Hudson, what should I do today?" Talk to them in plain English by name — Pippa, Cora, Dash, Otis, Sasha — or let Hudson route it.

03

Review & ship

Each agent produces real files or copy in your formats. Review the diff, then commit & push — or ask the agent to do it.
